# Security policy

## Supported version

Security fixes are applied to the current `main` branch. The project does not currently publish signed, versioned desktop releases, so older source snapshots and locally built application bundles are not supported release channels.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/dst0/miofive-video-converter/security/advisories/new). Do not include credentials, private media, filesystem contents, or other sensitive data in a public issue.

Include a minimal sanitized reproduction, affected commit, impact, and suggested remediation when known. You may use synthetic filenames and sample videos from `test-data`; do not upload real dashcam footage unless a secure transfer method has been explicitly agreed.

For ordinary non-security bugs, use the public issue tracker.
